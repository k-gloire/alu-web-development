# HTML Advanced

This project builds a headphone company webpage from a Figma design, using only semantic HTML. There is no CSS and no styling yet.

## What the page contains

- A header with a clickable logo and 3 navigation links
- A banner with a title, a short text and a button
- A section with a title and 4 blocks, each with an image, a name and a sub-title
